# cofferdam brand assets

Generated by `scripts/make-logo.sh`. Edit the script, not these files.

The server does not read this directory. It ships no static files, so
`src/logo.ts` carries the mark and the wordmark inline, and the same script
checks that those copies still match these ones. Run `make-logo.sh --check` to
report drift without writing anything.

The mark is a ring drawn as a rotation arrow with a square at its centre: the
ring is the enclosure and the square is what it keeps.

| File | Use |
| --- | --- |
| `cofferdam-mark.svg` | The glyph alone, single colour. Header logo, favicon source. |
| `cofferdam-icon.svg` | The glyph knocked out of a rounded teal tile. App icon, avatar, OG image. |
| `cofferdam-wordmark.svg` | `cofferdam` alone, single colour. |
| `cofferdam-wordmark-two-tone.svg` | `coffer` teal, `dam` ink. Marketing use, not UI chrome. |
| `cofferdam-lockup.svg` | Mark plus wordmark, horizontal. The default logo. |

## Colour

| Role | Hex |
| --- | --- |
| Ink | `#14201f` |
| Teal | `#0e7c74` |
| Paper | `#fbf8f3` |

`cofferdam-mark.svg` and `cofferdam-wordmark.svg` paint with `currentColor`, so they
inherit the surrounding text colour and work in every theme, `terminal` and
`midnight` included:

```html
<span style="color: var(--accent)">
  <!-- inline the mark here -->
</span>
```

The two-tone wordmark, the lockup, and the icon carry fixed colours. On a dark
surface use the single-colour files instead, or regenerate the icon with the
tile and glyph colours swapped.

## Geometry

The mark sits on a 64 x 64 box, ring centred at (32, 32) with radius 20, stroke
6, round caps. At its centre is a 14 x 14 square, corner radius 3. The
arrowhead is equilateral with side 13.5, which is 2.25 times the stroke; its
centroid sits on the ring at -122 degrees and it points along the tangent. The
arc runs clockwise from -55 degrees and stops one inradius short of that
centroid, so its round cap lands under the arrowhead's base rather than beside
it. Ring and arrowhead together span 9 to 55 on both axes, so the glyph is
centred in its box with 9 units of clear space already built in. Keep clear
space of at least half the square's width on all sides.

Every one of those coordinates is computed by `make-logo.sh` from the angles and
radii above. None of them should be typed by hand: the arc is the one shape
whose centre is implied by its endpoints rather than stated, so a hand-placed
endpoint silently moves the ring off the square, which is how an earlier version
of this file came to describe a mark it did not draw.

Both wordmark files share a 395 x 60 box: ascender 0, x-height 20, baseline 60,
stroke 10, round caps. Every bowl is a radius-15 circle centred on y = 40, and
letters carry 8 units of air between outer edges. Three letters are too narrow
for a full bowl and carry their own radii: f is 27 wide with a radius-10 head,
r has a radius-13 shoulder, and m's two arches are radius 11, so the letter is
not simply twice an n. The bowls of c and e are cut 50 degrees either side of
due east. Letters are strokes, not outlines, so there is no font dependency and
no text-to-path step. Scaling is uniform only -- never stretch one axis, since
the stroke weight is constant by construction.

In the lockup the mark is scaled to 0.875, which puts its ring's outer diameter
at 40.25, within a quarter unit of the wordmark's 40-unit x-height. That scale
also takes the mark's 64-unit box to 56, so it sits flush left, centred on the
wordmark's box at y = 2, and the wordmark starts at x = 76: the mark's box plus
20 units of clear space, for a 471 x 60 lockup.

## Small sizes

Below about 20 px the ring's stroke and the square start to merge. For a
favicon use `cofferdam-icon.svg`, whose tile holds its shape, or render a 16 px PNG
from the icon rather than from the bare mark.

## Don't

- Recolour the two words of the wordmark to anything but teal and ink.
- Add gradients, shadows, or outlines to the mark.
- Rotate the mark, or animate the ring in UI chrome.
- Set `cofferdam` in a system font next to the mark instead of using the wordmark.
