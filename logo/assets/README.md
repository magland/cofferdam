# Mochi Forge brand assets

Generated by `scripts/make-logo.sh`. Edit the script, not these files.

The server does not read this directory. It ships no static files, so
`src/logo.ts` carries the mark and the wordmark inline, and the same script
checks that those copies still match these ones. Run `make-logo.sh --check` to
report drift without writing anything.

The mark is a strike at the anvil: the workpiece square resting on the anvil's
face, with three sparks flying off the point of the blow. The wordmark sets the
short name, `mochi`, in the same monoline stroke and the same radius as the
mark's curves, so the two read as one drawing.

| File | Use |
| --- | --- |
| `mochi-mark.svg` | The glyph alone, single colour. Header logo, favicon source. |
| `mochi-icon.svg` | The glyph knocked out of a rounded teal tile. App icon, avatar, OG image. |
| `mochi-wordmark.svg` | `mochi` alone, single colour. |
| `mochi-lockup.svg` | Mark plus wordmark, horizontal. The default logo. |

## Colour

| Role | Hex |
| --- | --- |
| Ink | `#14201f` |
| Teal | `#0e7c74` |
| Paper | `#fbf8f3` |

`mochi-mark.svg` and `mochi-wordmark.svg` paint with `currentColor`, so they
inherit the surrounding text colour and work in every theme, `terminal` and
`midnight` included:

```html
<span style="color: var(--accent)">
  <!-- inline the mark here -->
</span>
```

The lockup and the icon carry fixed colours. On a dark surface use the
single-colour files instead, or regenerate the icon with the tile and glyph
colours swapped.

## Geometry

The mark sits on a 64 x 64 box, stroke 6, round caps. The workpiece is a
14 x 14 square with corner radius 3, resting half a stroke above the anvil
face, a 36-unit horizontal. The sparks are stroke segments radiating from the
square's top centre at -140, -90, and -40 degrees, from radius 11 out to
radius 19, so all three point back at where the hammer lands. The square's
height is not chosen but solved for: the ink margins above and below are set
equal, which puts the ink on 9.5 to 54.5 vertically and 11 to 53 across the
anvil, so the glyph is centred in its box with about 10 units of clear space
already built in. Keep clear space of at least half the square's width on all
sides.

Every one of those coordinates is computed by `make-logo.sh` from the angles
and radii above. None of them should be typed by hand: a hand-placed spark
silently stops pointing at the strike point, which is how an earlier version
of this file came to describe a mark it did not draw.

The wordmark sits on a 232 x 60 box: ascender 0, x-height 20, baseline 60,
stroke 10, round caps. Radius 15 is the only curve in the word and it is
centred on y = 40 throughout: o is a full circle of it, c is the same circle
cut open 50 degrees either side of due east so its two terminals sit level,
and the arches of m and h are its top half, springing from one stem at y = 40
and landing on the next. Letters carry 8 units of air between outer edges.
h's stem and i's tittle, a disc one stroke wide centred on the ascender line,
are the only ink above the x-height, and no letter descends, so the box stops
half a stroke below the baseline. Letters are strokes, not outlines, so there
is no font dependency and no text-to-path step. Scaling is uniform only --
never stretch one axis, since the stroke weight is constant by construction.

In the lockup the mark is scaled to 0.89, which takes its 45 ink units to
40.05, within a tenth of the wordmark's 40-unit x-height. It sits flush left
by its box and is centred on the ascender-to-baseline band, which with no
descender in the name is the middle of the wordmark's box as well. The
wordmark starts at x = 76.96: the mark's scaled box plus 20 units of clear
space, for a 308.96 x 60 lockup.

## Small sizes

Below about 20 px the sparks start to merge with the square. For a favicon
use `mochi-icon.svg`, whose tile holds its shape, or render a 16 px PNG from
the icon rather than from the bare mark.

## Don't

- Add gradients, shadows, or outlines to the mark.
- Rotate the mark, or animate the sparks in UI chrome.
- Set `mochi` in a system font next to the mark instead of using the wordmark.
- Set the wordmark in anything but the short name; "Mochi Forge" is text, not
  a logotype.
