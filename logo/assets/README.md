# feorge brand assets

Generated by `scripts/make-logo.sh`. Edit the script, not these files.

The server does not read this directory. It ships no static files, so
`src/logo.ts` carries the mark and the wordmark inline, and the same script
checks that those copies still match these ones. Run `make-logo.sh --check` to
report drift without writing anything.

The mark is a strike at the anvil: the workpiece square resting on the anvil's
face, with three sparks flying off the point of the blow. The name divides as
fe | orge, iron and the forge, which is what the two-tone wordmark colours.

| File | Use |
| --- | --- |
| `feorge-mark.svg` | The glyph alone, single colour. Header logo, favicon source. |
| `feorge-icon.svg` | The glyph knocked out of a rounded teal tile. App icon, avatar, OG image. |
| `feorge-wordmark.svg` | `feorge` alone, single colour. |
| `feorge-wordmark-two-tone.svg` | `fe` teal, `orge` ink. Marketing use, not UI chrome. |
| `feorge-lockup.svg` | Mark plus wordmark, horizontal. The default logo. |

## Colour

| Role | Hex |
| --- | --- |
| Ink | `#14201f` |
| Teal | `#0e7c74` |
| Paper | `#fbf8f3` |

`feorge-mark.svg` and `feorge-wordmark.svg` paint with `currentColor`, so they
inherit the surrounding text colour and work in every theme, `terminal` and
`midnight` included:

```html
<span style="color: var(--accent)">
  <!-- inline the mark here -->
</span>
```

The two-tone wordmark, the lockup, and the icon carry fixed colours. On a dark
surface use the single-colour files instead, or regenerate the icon with the
tile and glyph colours swapped.

## Geometry

The mark sits on a 64 x 64 box, stroke 6, round caps. The workpiece is a
14 x 14 square with corner radius 3, resting half a stroke above the anvil
face, a 36-unit horizontal. The sparks are stroke segments radiating from the
square's top centre at -140, -90, and -40 degrees, from radius 11 out to
radius 19, so all three point back at where the hammer lands. The square's
height is not chosen but solved for: the ink margins above and below are set
equal, which puts the ink on 9.5 to 54.5 vertically and 11 to 53 across the
anvil, so the glyph is centred in its box with about 10 units of clear space
already built in. Keep clear space of at least half the square's width on all
sides.

Every one of those coordinates is computed by `make-logo.sh` from the angles
and radii above. None of them should be typed by hand: a hand-placed spark
silently stops pointing at the strike point, which is how an earlier version
of this file came to describe a mark it did not draw.

Both wordmark files share a 250 x 75 box: ascender 0, x-height 20, baseline
60, descender 75, stroke 10, round caps. Every bowl is a radius-15 circle
centred on y = 40, and letters carry 8 units of air between outer edges. f is
27 wide with a radius-10 head, r has a radius-13 shoulder, and g answers f
with a radius-10 tail at the other end of the word's height, the one
descender in the name. The bowls of the two e's are cut 50 degrees either
side of due east. Letters are strokes, not outlines, so there is no font
dependency and no text-to-path step. Scaling is uniform only -- never stretch
one axis, since the stroke weight is constant by construction.

In the lockup the mark is scaled to 0.89, which takes its 45 ink units to
40.05, within a tenth of the wordmark's 40-unit x-height. It sits flush left
by its box and is centred on the ascender-to-baseline band rather than the
whole box, since the descender below the baseline is one letter's tail and
not part of the word's mass. The wordmark starts at x = 76.96: the mark's
scaled box plus 20 units of clear space, for a 326.96 x 75 lockup.

## Small sizes

Below about 20 px the sparks start to merge with the square. For a favicon
use `feorge-icon.svg`, whose tile holds its shape, or render a 16 px PNG from
the icon rather than from the bare mark.

## Don't

- Recolour the two words of the wordmark to anything but teal and ink.
- Add gradients, shadows, or outlines to the mark.
- Rotate the mark, or animate the sparks in UI chrome.
- Set `feorge` in a system font next to the mark instead of using the wordmark.
